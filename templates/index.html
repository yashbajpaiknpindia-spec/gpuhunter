Mining profiles & wallet configuration

Provider data can scan many coins, but each auto-mined algorithm needs a compatible, reviewed miner command and payout address.

1
Copy the example catalogdata/mining_profiles.example.json → data/mining_profiles.json
2
Add a verified profileSet the coin tag, algorithm, supported GPU models, miner image, start command, expected hashrate and log parser. Placeholder profiles are deliberately disabled.
3
Add public payout addressesdata/wallets.jsonUse only public receiving addresses. Never put seed phrases or private keys in the app.
4
Set up remote monitoringAdd the app's SSH public key to Vast, configure SSH_PRIVATE_KEY_PATH, and ensure the miner logs parseable hashrate plus accepted shares. Live rentals are destroyed if performance cannot be verified.
